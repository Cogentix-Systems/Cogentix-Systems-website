# Cogentix Systems Website

A modern and responsive website developed for **Cogentix Systems** to showcase the company's services, solutions, projects, and technology offerings.

## Features

- Responsive website design
- Home and About Us sections
- Services showcase
- Case Studies
- Blog section
- Careers section
- Contact Us form
- Interactive sliders and animations
- Responsive navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- Owl Carousel
- WOW.js
